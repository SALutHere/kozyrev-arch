# Акт 0: Скрипт в одном файле

**Ветка:** `act_0`

## Задача

Кладовщик космического завода просит утилиту для анализа инвентаря.

**Вводные:**
- CSV-файл с деталями (двигатели, корпуса, щиты, оружие, топливные баки)
- Разовая задача, не сервис

**Что на выходе:**
- Статистика по типам (количество + вес)
- Список деталей с нулевым остатком
- Вывод в консоль

## Пример вывода

```
Загружено 10 деталей из data/inventory.csv
Типы: [engine fuel_tank hull shield weapon]

=== Статистика склада ===

По типам:
  engine:     20 шт,   8446.0 кг
  fuel_tank:  25 шт,   4500.0 кг
  hull:        8 шт,   8850.0 кг
  shield:     15 шт,   3150.0 кг
  weapon:     20 шт,   1900.0 кг

Общий вес: 26846.0 кг

=== Отсутствуют на складе ===
  Плазменный щит ПЩ-3
  Криобак КБ-500
  Плазменная пушка ПП-3
```

## Ключевая мысль

> Это скрипт. Запустил → получил результат → закрыл.
> Не надо городить слои ради слоёв.

Весь код в `main.go`. Никаких пакетов, интерфейсов, слоёв.
Для одноразовой CLI-утилиты — это правильно.
